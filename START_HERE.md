## 🛡️ Security Considerations

### What's Secure:
- ✅ HTTPS encryption (Netlify provides)
- ✅ No payment data (no PCI compliance needed)
- ✅ No passwords (no authentication to manage)
- ✅ Customer data in Airtable (professional platform)
- ✅ Regular backups (Airtable handles)

### What to Know:
- ⚠️ Airtable token is in JavaScript (visible to tech-savvy users)
- ⚠️ Someone could theoretically submit fake orders
- ⚠️ No CAPTCHA (could add if spam becomes issue)

### Mitigation:
- Monitor orders regularly (you'll spot fakes)
- Can regenerate token anytime (invalidates old one)
- For more security, we can add serverless functions later
- **For a small farm, this is totally fine**
